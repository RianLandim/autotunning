# Desenvolvedor(a) Backend Python Pleno

Somos uma fintech de pagamentos e estamos ampliando o time de plataforma. Você vai construir e manter as APIs que processam transações dos nossos clientes.

## Requisitos
- 3 anos ou mais de experiência com Python em desenvolvimento backend
- Experiência com FastAPI ou Django na construção de APIs REST
- Bancos de dados relacionais (PostgreSQL de preferência)
- Docker e pipelines de CI/CD
- Experiência com serviços da AWS (ex.: Lambda, ECS, SQS, RDS)
- Inglês intermediário para leitura de documentação e reuniões ocasionais

## Diferenciais
- Experiência em fintech, pagamentos ou sistemas financeiros
- Mensageria (Kafka, RabbitMQ ou SQS)
- Certificação AWS

## O que oferecemos
- Trabalho remoto, plano de saúde, auxílio home office
- Buscamos pessoas proativas e apaixonadas por tecnologia!
